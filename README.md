# 💡 Bulb

> **Where ideas become bright.**

This is our idea vault — a place to capture, refine, test, and build interesting ideas.

## How we use Bulb

- 💡 **Capture** — save promising ideas before they disappear.
- 🔬 **Explore** — add research, assumptions, and experiments.
- 🚀 **Build** — turn the strongest ideas into real projects.
- 📈 **Learn** — record what worked, what failed, and why.

## Ideas

Ideas will live here as simple, version-controlled documents so we can evolve them over time.
